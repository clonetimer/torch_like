# FiLM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a tested observation-tier FiLM forecaster from the Workbuddy reports.

**Architecture:** Private LPU and FEL in a focused `film_layers.py`; public config
and forecaster in `film.py`. Use existing registry, serialization and lazy-export
generators without changing shared model behavior.

**Tech Stack:** Python >=3.10, PyTorch >=2.0, pytest, ruff, existing audit tools.

**Spec:** `docs/superpowers/specs/2026-10-31-film-design.md`

## Global Constraints

- Python >=3.10, PyTorch >=2.0; no new dependency, workflow, version or Stable change.
- Preserve 161 grandfathered registry entries and all existing 916 protected API records.
- Registry key `FiLM`, integration `paper_aligned_portable_subset`; maturity and benchmark evidence remain `unassessed`.
- Admission remains observation, A, value 82, risk 5, final 77.
- Scope and exact formulas/defaults are those of the spec; tests precede code.

## Review Focus

1. H=1, H>L and odd FFT lengths must retain DC and return the exact horizon (Task 2).
2. An imaginary coefficient weight must rotate a non-DC phase, not silently disappear (Task 2).
3. Multiscale long history must use the specified coefficient index, not the final state (Task 2).
4. Constant/nonfinite inputs and tiny/huge eps need explicit finite behavior or rejection (Task 2).
5. Float64 saved weights and fixed buffers must survive public restoration exactly (Task 3).
