**Goal:** Add an observation-tier native GMAN with mandatory supplied spatial
embeddings and calendar, verified mathematics and public persistence.

**Architecture:** Positionwise projections and population BN feed separate
spatial/temporal attention and gated residual blocks. Future calendar queries
attend to historical calendar keys and encoded traffic values before decoding.

**Tech Stack:** Existing Python>=3.10, torch>=2.0, pytest/Ruff; no new dependency.

**Spec:** `docs/superpowers/specs/2026-11-01-gman-design.md`.

- Admission observation70 (value76, A, risk6); qualifier no code until acceptance.

- Preserve924 old API records, grandfathered161, Stable/version/workflows/PR30.
- Require SE and raw integer weekday/slot calendar; never consume future traffic.

## Review Focus

- BN's all-time training moments do not imply causal prefix independence; test
  masked dependence with frozen/disabled BN and state updates separately.
- Cold untrained eval and singleton SE reductions must stay usable; explicit
  running-var1 adaptation, population variance and decay must match the spec.
- Future calendar is required but decoder values/prefix marks are unread; bad
  used marks must fail before any BN state mutation.
- Fixed-width integers and mutable SE/config aliases must not overflow geometry
  or corrupt exact float64 save/load and node ordering.
- A70 versus B62.4 is policy interpretation, not local benchmark evidence;
  copied TESTAM main rows and unpublished baseline artifacts cannot prove parity.
